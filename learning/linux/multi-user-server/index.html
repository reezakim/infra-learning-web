Multi-User Server Administration

Dokumentasi praktik eksperimen membangun dan mengelola server multi-user yang aman.

1

Objective

Merancang dan mengkonfigurasi server Linux multi-user dengan hak akses terisolasi, privilese terpusat via sudoers, serta direktori kolaborasi kelompok yang terproteksi.

2

Environment Specifications

OS Platform Ubuntu Server 24.04
Hypervisor VMware
CPU 2 CPU
Memory 2 GB RAM
Network Mode Bridged
Access Method SSH
3

Concepts Covered

  • Abstraksi User dan Group pada sistem POSIX.
  • Prinsip Least Privilege dan Kebijakan Sudoers (/etc/sudoers.d/).
  • Isolasi Home Directory (chmod 700) dan Restriksi Umask.
  • Kolaborasi Direktori menggunakan SGID (Setgid Bit) dan Sticky Bit.
4

Implementation Steps

  1. 01. Membuat group kerja khusus untuk departemen/proyek (misal: sysdevs).
  2. 02. Membuat akun pengguna terpisah tanpa akses root langsung dan mengonfigurasi SSH key authentication.
  3. 03. Mengkonfigurasi direktori bersama /var/projects/sysdevs dengan kepemilikan group dan SGID bit.
  4. 04. Mengatur aturan sudoers kustom untuk mengizinkan perintah tertentu tanpa akses penuh root.
5

Commands Reference

bash - multi-user-setup.sh 
# 1. Membuat group & user baru
sudo groupadd sysdevs
sudo useradd -m -g sysdevs -s /bin/bash engineer1

# 2. Mengatur direktori terbagi dengan SGID
sudo mkdir -p /var/projects/sysdevs
sudo chown -R root:sysdevs /var/projects/sysdevs
sudo chmod 2775 /var/projects/sysdevs

# 3. Menambahkan aturan sudo terisolasi
echo "engineer1 ALL=(ALL) /usr/bin/systemctl restart nginx" | sudo tee /etc/sudoers.d/engineer1
